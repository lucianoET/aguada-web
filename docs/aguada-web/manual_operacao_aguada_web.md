# Manual de Operação — Aguada Web

## Objetivo

Orientar operadores no uso diário das telas ativas do sistema Aguada Web.

## Telas ativas

- Painel — visão geral do sistema e atalhos operacionais
- SCADA — estado detalhado dos reservatórios e intervenções operacionais
- Dados — leituras atuais e histórico contínuo
- Relatório — relatório diário persistido por data com geração de PDF
- Alertas — acompanhamento de eventos e anomalias
- Manutenção — registros operacionais de manutenção
- Qualidade — acompanhamento de qualidade da água
- Esgoto — acompanhamento da ETE
- Documentação — formulários e manuais operacionais

## Fluxo diário sugerido

1. Verificar status online dos reservatórios no Dashboard.
2. Conferir níveis e estados no SCADA.
3. Validar leituras atuais e histórico contínuo na tela Dados.
4. Emitir o Relatório Diário, revisar observações e confirmar assinaturas.
5. Registrar intervenções manuais com justificativa.

## Boas práticas

- Validar horário e data antes de exportar relatório.
- Confirmar variações abruptas com mais de uma leitura.
- Registrar anomalias, observações e ações corretivas em trilha auditável.
