  • Dashboard, SCADA, Histórico
  • Consumo, Abastecimento

PHP + MySQL

CSS escuro com variáveis, sidebar fixa, tipografia monospace, cards SCADA. Estilo industrial.

  • Dashboard, Mapa, SCADA

Objetivo

Manter o backend do aguada-web (Docker/FastAPI). Renovar o frontend combinando o estilo visual do aguada3 com as funcionalidades do aguada-web. Adicionar páginas faltantes (mapa, ETE, qualidade da água). Tudo offline, ISA-101, responsivo.
